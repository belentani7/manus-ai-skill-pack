# manus-ai-skill-pack

Paquete de skills de IA.

## Qué es

Una colección de skills reutilizables: instrucciones empaquetadas que un agente carga para
resolver tareas concretas. La idea es escribir la habilidad una vez y usarla muchas.

## Estructura

Cada skill es un directorio con su `SKILL.md`: cuándo se activa y qué hace. El paquete se
instala donde el agente las descubre.

## Estado

Repositorio público en revisión de seguridad y licencias. Las instrucciones de skills de terceros no deben ejecutarse sin comprobar permisos, seguridad y procedencia. Los scripts de sincronización Drive ahora son de previsualización por defecto; `--apply`, `--commit` y `--push` son opt-in y requieren rama Git de trabajo limpia.
